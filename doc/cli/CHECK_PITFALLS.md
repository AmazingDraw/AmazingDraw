# CHECK_PITFALLS.md — 高频避坑速查

fill / 连抽前看这一页。全量规则在 [CHECK_SCRIPT_GUIDE.md](../engine/validation/CHECK_SCRIPT_GUIDE.md)。

| 坑 | 别这样写 | 改成 | 别误杀 |
| :--- | :--- | :--- | :--- |
| 嘴舌 | `biting lip` / `tongue out` / `drool` | `lips softly parted` 或 `pressing lips together` | — |
| 内裤+私处 | `panties` 和 `pussy`/`vulva` 同时出现 | `no panties` / `bottomless`，或内裤拉到一边 | 半遮只写裤边偷看、不写 vulva，可过 |
| 薄衣露点 | `no bra` + 白衬衫 + nipples，却没写衣襟打开 | `shirt open` / `unbuttoned` / `hanging open` | `open-back` 不算前敞；外敞但内衬扣好是合法半遮 |
| 无扣假敞开 | 吊带/背心/运动内衣只写 `hanging open`/`one shoulder` 却露奶头 | `pulled down` / `aside` / `removed`，或干脆 `topless` | 有扣 `shirt`/`blouse` 走上一行，不走本条 |
| 侧影单乳 | `profile`/`from the side` 却写复数 `breasts`/`nipples` | `only one breast visible` / `one nipple visible` | `outside view` 不算侧面 |
| 回眸折腰 | `from behind` + 胸部词紧挨 `exposed`/`visible`/`open`/`bare` | 后入只写 `one breast visible from the side` | `chest covered` / `top still covering the chest` 不计露胸 |
| 阴毛闭腿 | `pubic hair` + `legs closed`/`knees together`（真下体全露） | 配 `legs spread` / `knees apart`，毛写在 mons 正中向下 | 半遮裤边偷看最多软警告，不要硬改成分腿 |
| 站着露下 | 正面站立 + 露逼 + **明确并腿**（`legs closed` / `knees together`） | 删并腿词，或改重心偏一侧 / 微屈膝 / `thighs parted slightly` | **站着可以露逼。** 没写并腿不要硬加 spread。仰视/偷拍可免 |
| 精液 | 喷射；糊嘴/唇/鼻/下巴/睁眼；或写 `no semen` 声明没有 | 有：`SAFE_CUMS` 贴肤+半透明。没有：液体槽留空或 dew/sweat | 门禁已剥 `no semen`，填槽仍不要靠否定词 |
| 床/镜/自拍 | 裸写 `lying on bed`、`standing in front of mirror`；自拍写 `camera`、双手都在动 | 床加朝向；镜加 `from behind`；自拍用 `phone`/`lens`，单手 | 床上道具写到旁边架子/桌面，不要写在床上 |
| 纹身 | 只写 `tattoo`，或 `no tattoo`/`clean skin` | 要纹：`ink embedded in dermis, pores visible through ink`。不纹：槽留空 | 中文纹身加 `hand-drawn` / `permanent marker` |

服装写了 bra 移开，身材就不要再写 areolae/nipples。`body_shape` 由盲盒托管，不要在服装/姿势里写罩杯或体型尺寸。
