# WebUI 操作指南

> **定位**：WebUI（`http://127.0.0.1:8318`）管**看图、管卡、相册、盯队列、改设置**；出卡只用工作台的**直投 / 精选**。连抽与常规 fill 走 CLI（`card_cli --help`）。

---

## 1. 推荐分工

| 你想做什么 | 优先用 | 说明 |
| :--- | :--- | :--- |
| 建卡、填槽、连抽、过门禁、resume | **CLI**（Cursor 等本地 Agent） | 完整契约以 `card_cli --help` 为准 |
| 看成品图、切卡、清列表、盯 GPU 队列 | **卡片工作台 + 右侧队列** | 预览、筛选、停止/清空队列 |
| 分类成品 | **相册** | 收藏默认分类、专辑、拖入、按角色浏览 |
| 改模型 / 路径 / 画幅 / 工作流 | **配置页** | LLM 填 OpenAI 兼容 Base URL；改完保存即可 |
| 自备完整英文 Prompt 直投 | 输入框 **闪电** | 零改写投 GPU |
| 灵感库随机一条 | 输入框 **骰子** | 旁路灵感渲染 |

**一句话**：WebUI 负责「出卡快捷入口 + 看结果 + 相册」；精细打磨走 CLI。

---

## 2. CLI 默认：连抽

未指定模式 → 按 **chain** 执行（终端 / Agent，不是 WebUI）：

1. `chain --count N` 建骨架（可锁人物 / 场景 / 体型）
2. 每卡 **一次** `fill --json-file`（导演 + 槽位 + 叙事一次写齐，勿拆 `--phase`）
3. 逐张 `chain --resume <id>`：render → check → autofix → submit（引擎串行，勿并行 resume）
4. check 失败：`mend` 改字段后再 resume

细节与避坑见「命令速查」和 Agent 侧 `PROMPT_TEMPLATE` / `CHECK_PITFALLS`。出图后回 **卡片工作台** 看预览、处理队列即可。

---

## 3. 四种出图方式

| 优先级 | 方式 | 怎么进 | WebUI 角色 |
| :---: | :--- | :--- | :--- |
| CLI | 🚄 **连抽** | `chain --help` | 只看结果 / 队列 |
| CLI | 🎴 **常规** | `create --help` | 只看结果 / 队列 |
| WebUI | ⚡ **直投** | 输入框闪电 | 成品英文 Prompt，不经场景库 |
| WebUI | 🎲 **精选** | 输入框骰子 | 灵感库随机一条并入队 |

## 4. WebUI：页面与队列

右侧同一列：**卡片 / 相册 / 配置 / 文档**。刷新会停在当前页。

| 区域 | 用途 |
| :--- | :--- |
| 卡片 | 列表、状态筛选、预览参数；直投 / 精选出卡 |
| 相册 | 成品库网格、悬停收藏/删除、专辑、拖入分类 |
| 配置 | Comfy 路径、LLM Base URL、工作流、画幅、投递 |
| 文档 | 本指南及依赖 / SKILL / 配置 / 命令 / 赞助 |
| 右侧队列 | Idle / 排队 / 渲染中；取消当前、清空队列、终止任务（只停当前渲染并退出 ComfyUI，队列保留；会清理未提交的草稿卡） |

左上角圆点 = ComfyUI 是否在线。离线则队列不会真正出图。

输入框旁：

- **骰子**：精选，随机灵感库笔记建卡并入队
- **闪电**：直投，把完整英文 prompt 建卡并提交渲染

列表维护：状态筛选 + 清理缺图卡 / 草稿 / 残留排队。清理要在 WebUI 里显式确认，抽卡流程不会后台自动删草稿。成品图路径见配置里的 `output_dir` / 归档盘。

数字快捷（`1` 提交、`2`–`8` 改方向等）只存在于 **CLI**，以 `card_cli` 帮助为准。

## 5. 设置（本机一次配好）

| 区块 | 常见项 |
| :--- | :--- |
| 模型 | OpenAI 兼容 Base URL + 主模型。独立调用总闸默认开，可按节点关。不替代出图模型 |
| 路径 | `output_dir`、归档、灵感库、ComfyUI 目录 |
| 工作流 | 默认 Comfy workflow（现默认 Moody ZIB+ZIT） |
| 画幅 | 竖 / 横 / 方 / 宽屏 |
| 算法 | 防重复冷却、自动横屏、特殊视角等 |
| 投递 | 发图到 WebUI、Telegram |

## 7. 排障

| 现象 | 处理 |
| :--- | :--- |
| WebUI 有卡无图 | 看 Comfy 圆点；看队列是否失败 / 锁死 |
| resume 失败 | 读 check 输出 → mend → 再 resume |
| 工作台不出图 | 直投用闪电、精选用骰子；连抽 / 常规走 CLI |
| 直投被改写 | 确认走的是闪电 / 直投，不是常规 fill |
| 列表乱 | 筛选 + 清理缺图 / 草稿 / 残留排队 |

---

## 8. 最小闭环

1. **工作台**：闪电直投，或骰子精选入队
2. **右侧队列**：看 Idle / 排队 / 渲染；必要时停止 / 清空
3. 连抽、常规 fill 走 CLI；出图后回工作台或相册看结果
