# Amazing Draw · WebUI 操作指南

> **定位**：WebUI（`http://127.0.0.1:8318`）管**看图、管卡、盯队列、改设置**；抽卡创作走 **Draw 对话**（本机 AI + `card_cli`），也可以在 Cursor 等本地 Agent 里直接跑 CLI。
> 未指定模式时，抽卡默认按 **连抽（chain）**。输入框旁的闪电 / 骰子是直投和精选的快捷入口。

---

## 1. 推荐分工

| 你想做什么 | 优先用 | 说明 |
| :--- | :--- | :--- |
| 建卡、填槽、连抽、过门禁、resume | **抽卡页 Draw 对话** 或本地 Agent + CLI | 完整契约以 `card_cli --help` 为准 |
| 看成品图、切卡、清列表、盯 GPU 队列 | **卡片页 + 右侧队列** | 预览、筛选、停止/清空队列 |
| 改模型 / 路径 / 画幅 / 工作流 | **配置页** | 改完保存即可 |
| 自备完整英文 Prompt 直投 | 输入框 **闪电** 或 Draw「直投」 | 零改写投 GPU |
| 灵感库随机一条 | 输入框 **骰子** | 旁路灵感渲染 |

**一句话**：Draw 对话负责「策划与抽卡」；卡片页负责「看结果与运维队列」。

---

## 2. 抽卡默认：连抽

未指定模式 → 按 **chain** 执行（Draw 里点「连抽」，或对 AI 说连抽）：

1. `chain --count N` 建骨架（可锁人物 / 场景 / 体型）
2. 每卡 **一次** `fill --json-file`（导演 + 槽位 + 叙事一次写齐，勿拆 `--phase`）
3. 逐张 `chain --resume <id>`：render → check → autofix → submit（引擎串行，勿并行 resume）
4. check 失败：`mend` 改字段后再 resume

细节与避坑见「命令速查」和 Agent 侧 `PROMPT_TEMPLATE` / `CHECK_PITFALLS`。出图后回 **卡片页** 看预览、处理队列即可。

## 3. 四种出图方式

| 优先级 | 方式 | 怎么进 | WebUI 角色 |
| :---: | :--- | :--- | :--- |
| ⭐ 默认 | 🚄 **连抽** | Draw 点「连抽」，或说话 | 对话出卡；卡片页看图 / 队列 |
| 补充 | 🎴 **常规** | Draw 点「常规」，或 `create` | 单卡打磨；数字微调在对话里走 CLI 契约 |
| 补充 | ⚡ **直投** | 输入框闪电，或 Draw「直投」 | 成品英文 Prompt，不经场景库 |
| 补充 | 🎲 **精选** | 输入框骰子 | 灵感库随机一条并入队 |

---

## 4. WebUI：页面与队列

左侧同一列：**卡片 / 抽卡 / 配置 / 文档**。刷新会停在当前页。

| 区域 | 用途 |
| :--- | :--- |
| 卡片 | 列表、状态筛选、预览参数；在卡片页发送会带到抽卡会话 |
| 抽卡 Draw | AI 对话出卡。右侧工作台：新建会话、连抽、常规、直投 |
| 配置 | Comfy 路径、工作流、画幅、限制角色、投递 |
| 文档 | 本指南及依赖 / SKILL / 配置 / 命令 / 赞助 |
| 右侧队列 | Idle / 排队 / 渲染中；停止当前、清空队列、终止队列（慎用） |

左上角圆点 = ComfyUI 是否在线。离线则队列不会真正出图。

输入框旁：

- **骰子**：精选，随机灵感库笔记建卡并入队
- **闪电**：直投，把完整英文 prompt 建卡并提交渲染

列表维护：状态筛选 + 清理缺图卡 / 草稿 / 残留排队。清理要在 WebUI 里显式确认，抽卡流程不会后台自动删草稿。成品图路径见配置里的 `output_dir` / 归档盘。

---

## 5. Draw 对话（可选但常用）

抽卡页右侧可直接点模式，效果是往对话里发送对应指令（「进入连抽模式」等），再由 AI 按 CLI 执行。

常规里的数字快捷（`1` 提交、`2`–`8` 改方向、`9` 纹身、`0` / 「换」换场景）是 **CLI 交互契约**，不是页面上的按钮；以 `card_cli` 帮助为准。批量连抽和复杂门禁修复，用连抽而不是只在卡片页闲聊。

## 8. 排障

| 现象 | 处理 |
| :--- | :--- |
| WebUI 有卡无图 | 看 Comfy 圆点；看队列是否失败 / 锁死 |
| resume 失败 | 读 check 输出 → mend → 再 resume |
| 只聊天不出图 | 未提交；或应走连抽 / 闪电，而不是只闲聊 |
| 直投被改写 | 确认走的是闪电 / 直投，不是常规 fill |
| 列表乱 | 筛选 + 清理缺图 / 草稿 / 残留排队 |

---

## 9. 最小闭环

1. **抽卡页**：新建会话 → 点连抽（或直接说要抽几张）→ fill → resume 出图
2. **卡片页**：看图、确认队列，必要时停止 / 清空
3. 单卡死磕用常规；自带英文用闪电；碰运用骰子
